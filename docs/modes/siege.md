# 三路城堡攻防戰模式 (3-Lane Castle Siege / MOBA) 規格書

本文件為《光暈戰記》**三路城堡攻防戰 (`siege`)** 模式之專屬規格書，涵蓋 5v5 陣營限制、綁定英雄配置、技能與天賦表、經濟裝備強化、兵線／防禦塔／Boss 時間軸及塔防專屬 HUD 設計。共通系統與 2.5D 物理請參閱 [遊戲通用知識 (`../general-knowledge.md`)](../general-knowledge.md)。

---

## 1. 模式定位、陣營限制與多人連線同步規則

- **5v5 雙陣營推塔戰**：本模式僅開放 **`royal`（皇家騎士團）** 與 **`shadow`（天影十字軍）** 對決，**不開放第三勢力 (`mercenary`)**，勝利條件為摧毀敵方主城堡或於時間結束後結算優勢。
- **多人連線模式切換與持久化 (`worker/index.ts` & `MultiplayerLobbyView.tsx`)**：
  - 切入 `siege` 模式時（含加入房間、切換模式、更新設定、開戰），伺服器 `enforceSiegeFactions()` 會自動將原本選取 `mercenary` 的玩家強制分配至 `royal` 或 `shadow` 並校正為該陣營有效預設造型。
  - **戰局結束保持模式**：打完三路城堡攻防戰返回多人大廳時，房間 `mode` 與局時設定 `siegeDurationSec` 必須維持為 `siege`（不可自動彈回經典混戰）。
  - 房內選角介面採視覺化**綁定英雄戰術卡片**展示主槍、近戰、被動、戰技與大招（非孤立裸下拉選單）。

## 3. 等級解鎖、主動戰技、終極大招與被動天賦

- **技能解鎖門檻**：英雄 **Lv.2** 解鎖 `[E]` 主動戰技；**Lv.4** 解鎖 `[Q集氣]` 終極大招（未達等級前於底部主控台清楚顯示鎖定等級標記，且切換為近戰武器時可長按集氣施放）。

### 主動戰技 (`[E]`，Lv.2 解鎖)
- **皇家**：
  - `鐵壁反震盾` (`CD 12s`)：展開 `3.5s` 減傷 `60%` 的聖光反震盾，並將 `35%` 遠程傷害反彈給攻擊者（開火不破盾）。
  - `聖域光幕` (`CD 14s`)：於腳下展開持續 `4.5s`、半徑 `160px` 聖域光環，持續為圈內友軍回復 `+14 HP/s` 並減傷 `25%`。
  - `破陣衝鋒` (`CD 10s`)：向游標方向突進最高 `190px`，落點震飛周圍敵軍並造成 `25` 傷害與 `0.8s` 暈眩。
- **天影**：
  - `瞬影殘步` (`CD 11s`)：向游標方向瞬影突進 `190px` 並於原地留下殘影爆彈，`1.4s` 後引爆造成 `38` 範圍傷害與 `0.5s` 暈眩。
  - `鷹眼獵殺` (`CD 13s`)：開啟 `4.5s` 鷹眼視距強化並標記前方敵人 `5s`，被標記目標承受所有傷害額外 `+22%`。
  - `影霧隱身` (`CD 12s`)：進入 `3.5s` 影分身煙霧狀態（`2/3` 機率閃避遠程彈道），同時獲得 `+22%` 移動速度加成。

### 終極大招 (`[Q集氣]`，Lv.4 解鎖，升級「大招」至 Lv.3 解鎖進階型態)
- **皇家**：
  - `審判光柱`：黃金貫穿光柱（敵軍 `75` 傷，對防禦塔／主堡／Boss 造成 `180` 破甲重創，絕不傷隊友）。
  - `連珠光雨`：前方扇形齊射 `9` 發貫穿聖光彈（每發 `28` 傷，無友軍誤傷）。
  - `治癒聖彈`：`5` 發貫穿聖光波，對敵軍 `32` 傷同時為友軍英雄與小兵回復 `+35 HP`。
- **天影**：
  - `雙影噬龍`：召喚兩條高速深紫黑龍沿左右夾角突進（龍頭 `24`／龍身 `16` 傷，可反彈 `3` 次）。
  - `極速貫穿龍`：無視實牆與地形阻擋的幽冥長龍（`55` 傷、`1500px` 超遠射程）。
  - `盤龍結界`：於目標點化作持續 `3.5s`、半徑 `135px` 盤龍漩渦，每 `0.45s` 對圈內敵軍與建築造成 `16` 傷。

### 被動天賦 (`SIEGE_PASSIVES`)
- **皇家**：`聖殿堅壁`（最大血量 `+25`，承受塔／主堡砲擊 `-15%`）、`先鋒旗幟`（跑速 `+10%`，身邊 `240px` 友軍小兵傷害 `+20%`）、`精密準星`（槍械散布 `-25%`，換彈速度 `+15%`）。
- **天影**：`冥影追獵`（對生命低於 `45%` 敵人傷害 `+20%`，殺敵回氣 `+18`）、`暗影疾步`（跑速 `+12%`，自然回氣與集氣 `+25%`）、`破城死神`（對敵方英雄與 Boss／野怪傷害 `+15%`）。

## 4. 經濟、裝備升級路線與慢回彈節奏

- **金幣與回復**：被動金幣收入 **`+2G/s`**，另有補兵、擊殺、拆塔與搶野賞金；按 **`[B]` 回城**需讀條 `3.5s` 返回己方泉水，泉水內回復 **`+28 HP/s`**。
- **慢速回彈鼓勵近戰與戰術取勝**：
  - 塔防與連線團戰中，子彈脫戰自動回復採慢速節奏（`outOfCombatAmmoDelaySec: 4.0s`，之後每秒僅回復 `1.2` 發）；擊殺敵軍可額外獲得 `+6` 發備彈補給。設計意圖是避免無限遠程對耗，鼓勵玩家善用近戰武器、戰技與走位取勝。
- **四大升級路線（按 `[3]`–`[6]` 即時購買，每條上限 5 級）**：
  - 升級費用曲線（Lv.1 → Lv.5）：**`120 / 240 / 400 / 600 / 850 G`**

| 按鍵 | 路線名稱 | 每級強化內容 |
| --- | --- | --- |
| `[3]` | **槍械改造** (`firepower`) | 槍傷 `+12%` · 有效射程 `+8%` · 建築/Boss `+12%` · 換彈加快 `6%` |
| `[4]` | **戰技強化** (`blade`) | 戰術技傷害/治療/時長 `+25%` · 範圍/位移 `+8%` · CD `-8%` · 近戰傷害 `+14%` |
| `[5]` | **重甲護體** (`armor`) | 最大血量 `+32` · 防禦 `+3` · 移動速度 `+4%` |
| `[6]` | **終極秘技** (`core`) | 大招傷害/治療 `+25%` · 集氣/回氣 `+14%` · 升至 **Lv.3** 解鎖進階強化型態 |

## 5. 戰場節奏、兵線、防偷塔與中立野怪／Boss 時間軸

- **局時與驟死機制**：可選 **`15` 分鐘（快節奏）／`18` 分鐘（標準，預設）／`20` 分鐘（史詩）**；最後 **`180s`** 進入驟死加速（出兵間隔由 `22s` 縮短至 `15s`，建築承傷倍率 **`1.35×`**）。
- **三路兵線**：開局 `8s` 首波出兵、常態每 `22s` 一波，場上小兵活躍上限 `36` 隻；近戰小兵／近戰 AI 積極貼身近戰交鋒（不風箏後退）。
- **防偷塔保護**：敵方防禦塔／主堡周圍半徑 **`310px`** 內若無己方小兵，承受傷害降至 **`0.35×`**。
- **中立野怪與大型目標**：
  - **小型野怪**：開局 `35s` 首刷、擊殺後 `80s` 重生。
  - **裂谷先鋒**：開局 `180s` 首刷、`180s` 重生。
  - **遠古巨神 (Baron)**：開局 `480s` 首刷、`240s` 重生，擊殺賦予 **`90s`** 全隊強效推塔 Buff。

## 6. 三路攻防戰專屬 HUD 與視覺規範

- **左上雙環血量與英雄卡**：雙環直接顯示**實際 HP 點數**（如 `132 / 132`）而非百分比，搭配簡潔英雄卡（頭像、英雄名稱、等級 `Lv`、經驗條、防禦力與金幣）。
- **底部 MOBA 戰術主控台**：統一整合 `[E]` 主動戰技（顯示 `Lv.2` 鎖定與冷卻）、`[Q集氣]` 終極大招（顯示 `Lv.4` 鎖定與氣條進度）、`[B]` 回城鈕，以及 `[3]`–`[6]` 四張色彩分明的升級圖磚（每格附帶 `5` 顆視覺化階級點與費用標示）。
- **塔防戰術小地圖 (`SiegeMinimap`)**：即時呈現三路防禦塔與主堡存續、英雄／兵線與野怪／先鋒／巨神刷新狀態。
